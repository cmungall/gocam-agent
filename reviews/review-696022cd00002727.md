## Issues

### 1. Mixed Species Gene Products (Major)

The model declares both mouse (NCBITaxon:10090) and rat (NCBITaxon:10116). NMDAR subunits use **rat** identifiers (RGD:2736 Grin1, RGD:2738 Grin2b) while all other gene products use **mouse** MGI identifiers. GO-CAM models should represent a single organism. If experimental data comes from rat, the mouse orthologs should be used (or vice versa), with the evidence referencing the original paper.

### 2. GO:0005515 (protein binding) Too Generic (Major)

Activity node `696022cd00004100` uses **GO:0005515 (protein binding)**, which is overly generic and discouraged in GO-CAM. A more specific child term should be selected. Additionally, this activity **lacks an `enabled_by` (RO:0002333) edge** -- no gene product is assigned. All edges on this activity also **lack evidence**.

### 3. Incorrect Causal Direction: Dynamin -> AMPAR (Major)

Dynamin GTPase activity (`69729a3800000183`) connects to AMPAR activity (`696022cd00004110`) via **directly positively regulates (RO:0002630)**. Dynamin mediates vesicle scission during endocytosis, which **removes** AMPARs from the postsynaptic membrane, reducing their surface activity. This should be **directly negatively regulates (RO:0002629)** or **indirectly negatively regulates (RO:0002406)**, since the mechanism is multi-step (scission -> vesicle internalization -> reduced surface AMPARs).

### 4. Incorrect Causal Direction: Hippocalcin -> AP-2 (Moderate)

Hippocalcin calcium ion binding (`696022cd00004221`) connects to AP-2 adaptor activity (`696022cd00004216`) via **directly negatively regulates (RO:0002629)**. Published literature (Palmer et al., 2005) indicates hippocalcin is a calcium sensor that **promotes** AMPAR endocytosis by facilitating AP-2 complex recruitment. This should be **directly positively regulates (RO:0002630)**.

### 5. Duplicate/Orphan AP-2 Adaptor Nodes (Moderate)

Four separate clathrin-cargo adaptor activity (GO:0035615) nodes exist:
- `696022cd00004210`: enabled_by Ap2m1, has_input Cacng2
- `696022cd00004216`: enabled_by Ap2m1, has_input Gria2
- `69729a3800001369`: enabled_by AP-2 complex -- **no BP, CC, or evidence (orphan stub)**
- `69729a3800001379`: enabled_by AP-2 complex, has_input Hpca and Gria2

Node `69729a3800001369` appears incomplete and should be removed or completed. Representing the same function with both the individual subunit (Ap2m1) and the complex (GO:0030122) is confusing and potentially redundant.

### 6. Edges Missing Evidence (Moderate)

Several edges lack supporting evidence:
- Calcineurin -> Pick1 AP-2 binding (one of two duplicate edges has no evidence)
- All edges on the protein binding activity (`696022cd00004100`)
- AMPAR complex has_part edges (Cacng2, Gria2, Gria1)
- Several AP-2 adaptor activity edges (enabled_by, part_of, occurs_in, has_input)
- Hippocalcin activity edges (enabled_by, part_of, occurs_in)
- Cacng2 phosphorylation-dependent binding -> AMPAR: no evidence

### 7. CaMKII `part_of` Excitatory Postsynaptic Potential (Minor)

CaMKII kinase activity is annotated as `part_of` GO:0060079 (excitatory postsynaptic potential). CaMKII is activated during EPSPs but its kinase activity is not itself part of generating the EPSP. Consider `part_of` GO:0060292 (long-term synaptic depression) or GO:0048168 (regulation of neuronal synaptic plasticity) to match the model's biological context.

### 8. Duplicate Fact Entries (Minor)

The Dynamin GTPase -> AMPAR activity edge (RO:0002630) is represented as ~7 separate fact entries with overlapping evidence sets, all citing PMID:25810514. These should be consolidated into a single edge with all evidence instances attached.

Similarly, Pick1 AP-2 binding -> glutamate receptor binding (`696022cd00002738 -> 696022cd00003416`) appears twice (once with evidence, once without).

### 9. PMID Formatting (Minor)

Several evidence references have extra spaces in the PMID identifier (e.g., `PMID: 16138078`, `PMID: 28855251`, `PMID: 15664178`). These should be `PMID:16138078` (no space after colon).

### 10. PP1 `part_of` Clathrin-Dependent Endocytosis (Minor)

PP1 (Ppp1ca) phosphatase activity is annotated as `part_of` GO:0072583 (clathrin-dependent endocytosis). While PP1 dephosphorylation facilitates endocytosis, PP1 is a general phosphatase. Consider `part_of` GO:0060292 (long-term synaptic depression) to match the calcineurin activity's BP annotation.

## Recommendations

1. **Fix causal directions** for Dynamin->AMPAR (should be negative/indirect negative) and Hippocalcin->AP-2 (should be positive)
2. **Replace GO:0005515** with a more specific binding term and add an `enabled_by` gene product
3. **Standardize to one species** (mouse or rat) for all gene products
4. **Remove or complete** the orphan AP-2 adaptor node `69729a3800001369`
5. **Consolidate duplicate edges** (Dynamin->AMPAR, Pick1 AP-2->glutamate receptor binding, calcineurin->Pick1)
6. **Add missing evidence** to unsupported edges
7. **Fix PMID formatting** (remove spaces)
